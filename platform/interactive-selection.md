# Интерактивный отбор списка

Контракт переиспользуемого выбора строк галочками в терминале. Команда
передаёт готовые строки и забирает отмеченное подмножество. Компонент не
знает, откуда строки взялись: ни про SCM, ни про `git`, ни про смысл команды.

## Трассировка вверх

- [Обратная связь в терминале][terminal-feedback]

## Вход

| Вход | Смысл |
| ---- | ----- |
| Строки | Упорядоченный список. У строки есть видимый текст и необязательный адрес |
| Терминал | Стандартный ввод и вывод текущей сессии |

Как собрать видимый текст, здесь не задаётся. Список репозиториев использует
[полное имя][report-console] из вывода команды `report`.

## Поведение

Если стандартный ввод или вывод — не терминал, компонент ничего не рисует и
сообщает вызывающему, что интерактивный ввод недоступен. Код выхода задаёт
команда.

Иначе на терминале список с галочками. Изначально все галочки сняты.

Каждая строка показывает видимый текст. Если у строки задан адрес и вывод —
терминал, текст является гиперссылкой на этот адрес (OSC 8).

Набранный текст оставляет на экране строки, в видимый текст которых фрагмент
входит без учёта регистра. Галочки строк, скрытых фильтром, сохраняются.

Enter подтверждает набор галочек, в том числе пустой. Порядок результата —
порядок исходного списка, не порядок строк на экране после фильтра.

ESC отменяет выбор целиком. Код выхода задаёт команда, которая вызвала отбор.
Компонент каталоги не создаёт и не удаляет.

## Не здесь

- Код выхода конкретной команды.
- Правило полного имени репозитория —
  [вывод `report` на консоль][report-console].

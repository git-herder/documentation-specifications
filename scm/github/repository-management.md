# Управление репозиториями (GitHub)

Контракт компонента **GithubRepositoryManagement**: проверить владельца и
репозиторий на GitHub и создать репозиторий. Запросы идут через
[HTTP-транспорт][transport]. Повтора запроса здесь нет.

## Трассировка вверх

- [Публикация локальных рабочих копий в SCM][publish]
- [Обобщённая карточка репозитория][card] — поля `path` и `name`
- [ADR-26101703][adr-http] — обёртка над `net/http`

## Путь

Полный путь — `path` и `name` через `/`. `path` — ровно один сегмент, login
владельца. `name` — имя репозитория. Пустой `path`, пустой `name` или
`path` из нескольких сегментов — ошибка контракта до HTTP.

## Проверка репозитория

|              |                              |
| ------------ | ---------------------------- |
| Метод и путь | `GET /repos/{owner}/{repo}`  |
| `{owner}`    | единственный сегмент `path`  |
| `{repo}`     | `name`                       |

`200` — репозиторий для вызывающего есть. `404` — нет. Скрытый чужой
репозиторий платформа тоже отдаёт как `404`. Прочий код — ошибка вызова.

## Проверка владельца

Сначала `GET /orgs/{owner}`. `{owner}` — единственный сегмент `path`.

- `200` — владелец организация.
- `404` — затем `GET /users/{owner}`. `200` — владелец пользователь.
  `404` — владельца нет.
- Прочий код на любом из двух запросов — ошибка вызова. Второй запрос
  после такого кода не выполняется.

Организацию и пользователя компонент не создаёт.

## Создание репозитория

Тело запроса — объект с одним полем `name`, равным `name` карточки.
Видимость, описание и README компонент не передаёт.

Владелец-организация: `POST /orgs/{org}/repos`. `{org}` — сегмент `path`.

Владелец-пользователь: сначала `GET /user`. Поле `login` ответа должно
совпасть с сегментом `path`. Иначе ошибка до создания, `POST` не
отправляется. При совпадении — `POST /user/repos`.

Успех создания — `201`. Прочий код — ошибка вызова. Если проверка дала
`404` из-за скрытого репозитория, создание завершается ошибкой API.
Компонент не подменяет её успехом.

## Не здесь

- Повтор неуспешного вызова. Транспорт ошибку не повторяет.
- Код выхода команды и политика «репозиторий уже есть».
- Как из каталога workspace собираются `path` и `name`.
- Изменение и удаление репозитория.
